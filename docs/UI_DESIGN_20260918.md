# OPNsense Manager UI refinement

## Direction and scope

Operate mode: a professional firewall console within PegaProx. Preserve the existing dark, light and cloud themes, nine destinations, native controls, permissions and fast data paths. System typography is intentional for a frequently used administrative tool; no external fonts, framework or animation dependencies.

| Before | After | Why |
|---|---|---|
| Small product title and a loading label that persists in HA | Product identity, dynamic version, effective access status and actual HA context | Make scope and permission visible |
| HA children inherit page column spans and create implicit columns | Two balanced node panels with explicit internal layout | Compare nodes reliably |
| Low hierarchy and bracketed technical headings | Readable section headings, quieter surfaces and consistent table density | Faster scanning |
| Nine mobile destinations behind horizontal scrolling | All nine destinations visible in a compact grid | Discover every section without scrolling the tab strip |
| Repeated card entrance animation during polling | Immediate content and brief control feedback | Preserve responsiveness |

## Acceptance

- Keep all endpoint paths, optimistic revisions, permission gates and write lifecycle unchanged.
- Read-only lists precede their disabled editors; forms and fields remain available.
- Health controls version and access labels; loading/failed discovery must not claim write access.
- Three themes; 390, 768, 1024 and 1440 px; keyboard tab navigation, visible focus and reduced motion.
- Existing browser regressions plus actual read-only production data rendered with the candidate HTML before deployment. Validate screenshot layout, contrast and all nine tabs in a single batched inspection, then one corrective pass if needed.
- Release with independent QA, backup verification, exact deployed file hashes and no firewall object mutations.
